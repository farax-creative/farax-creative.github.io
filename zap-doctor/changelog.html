Changelog

What changed in each release of Zap Doctor. Updates are free for everyone who owns it.

1.3.0 Latest 2026

Four new checks bring the total to 34, and an optional Render Guard can move the scan to the moment you render. Both guard switches ship off, so nothing about an existing setup changes on update.

Added — checks

  • Render passes a format can’t store: passes such as Mist, Normal or Cryptomatte are enabled, but the output format cannot save them. One click switches to OpenEXR MultiLayer.
  • Video output splitting at 2 GB: a long video render that would silently break into several files. One click turns autosplit off.
  • Compositor File Output node that writes nothing: a File Output node with no outputs, nothing connected, or an unreachable drive, so the render finishes but the pass never lands on disk.
  • Frame range past the last keyframe: a range running well beyond the end of the animation, rendering still frames by the hundred. One click trims it to the real range.

Added — Render Guard (optional, off by default)

  • Guard the render shortcut: F12 and Ctrl+F12 scan first, then render straight through if the scene is clean.
  • Report errors in background renders: blender -b renders print blocking issues to the console before starting, so a render-farm log carries them. Can also be switched on per job with ZAP_DOCTOR_RENDER_GUARD=1.

Notes

  • Render Guard reports; it never aborts a render that has already started, because Blender gives an add-on no way to do that.
  • The shortcut guard leaves the Industry Compatible keymap alone, where F12 is not bound to render, rather than adding a shortcut you never had.
  • Existing checks and their messages are unchanged, so any “always ignore” settings carry over intact.

1.2.1 2026

Maintenance release. Adds a Report a Bug link in the panel and tidies the build.

1.0.0 First release

Scan a Blender scene for the mistakes that ruin final renders, grouped by severity, with a one-click fix on the ones where the fix is unambiguous and a Revert log for every change made.
