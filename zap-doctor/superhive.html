05Questions
Does it run on its own or send anything anywhere?

No. By default it scans only when you press the button, with no network access at all. Render Guard, off by default, is the one thing that adds an automatic scan — and you turn it on yourself.

Can Render Guard stop a bad render for me?

It stops you before the render starts, by showing what would go wrong. Once a render has begun, Blender gives an add-on no way to abort it, so we don’t claim to. Renders started from the menu or command line go around the shortcut — the background report covers those.

Will it slow down a heavy scene?

Scan time follows how many textures you reference and where they live, not the object count — a big scene with local textures is quick.
