Changelog

What changed in each release of Zap Board. Updates are free for everyone who owns it.

2.0 Free & Pro

Zap Board gains a Pro tier. The free board stays free and complete; Pro adds the colour, video and 3D tools as a one-time $5 unlock in the same listing.

Added · Pro

  • Video & GIF reference: play a clip on the board with a scrub bar and transport controls, step frame by frame, and turn any frame into a still card.
  • Colour tools: Extract Palette lays an image's main colours out as swatch cards, pick a colour off any card, and sort a shelf of references by colour.
  • Image adjust: brightness, contrast, temperature and saturation on any card, without changing the file on disk.
  • Layout: layout templates and auto layout.
  • Send to the 3D view: place selected references in the viewport at the cursor, and remove them again with one button.
  • Board files: export and import a board, and copy an image's files next to the .blend.
  • Frames: a custom colour per group frame.

Added

  • Paste from a URL: add an image straight from a web address. It is the one feature that uses the network, and only when Blender's online access is on.
  • Rename a frame in place from the board.

Compatibility

  • Runs on Blender 4.5, 5.0, 5.1 and 5.2, on Windows, macOS and Linux. Reveal File opens the folder on Windows only.
