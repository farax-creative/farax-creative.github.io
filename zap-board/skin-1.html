07 / Limits

What Zap Board is built for.

A reference board inside one Blender file. Here is where that stops.

  • One file at a time

    A board lives in one .blend. It is a working reference board, not a searchable asset library.

  • Image Editor, not the viewport

    Boards live in Blender's Image Editor. Send to 3D (Pro) turns a card into an image plane in the scene.

  • Clips stay outside the .blend

    Blender cannot store video inside a .blend. Copy Files Next to .blend or Export Board + Images carries them.

  • Packing adds size

    Pack Pictures Into .blend makes the file about as large as the references you packed.

  • One Windows-only shortcut

    Reveal File opens Explorer on Windows. On macOS and Linux it tells you so and does nothing.
