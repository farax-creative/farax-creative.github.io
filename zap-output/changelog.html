Changelog

What changed in each release of Zap Output. Updates are free for everyone who owns it.

1.2.0 Latest

The first update since 1.0.2. It finds the frames an overnight render lost, keeps compositor passes from writing over the previous take, and warns you about a render that is going to finish with nothing written. Tested on Blender 5.0, 5.1 and 5.2.

Added

  • Render ContinuityPro: Scan Frames reports which frames are missing from a sequence, Set Range to Gaps points the frame range at the holes so the next render fills only them, and Scan Versions lists every take with its frame count.
  • File Output nodes follow Version UpPro: a node path that already carries a version moves with the render, to the version the render actually landed on. On by default, with an off switch in Preferences.
  • Preflight warnings in the path preview: Overwrite off with files already at that path, an output folder that refuses writes, a File Output node that will write nothing, and passes that will be lost because Post Processing is off.
  • Report a Bug in Preferences, with your add-on version, Blender version and OS filled in.

Changed

  • Archive on Version UpPro now moves the old version's render files into _old beside it, instead of moving whole folders. When it cannot be sure which files belong to the old version, it declines and says why.
  • Version Up checks the whole frame range for existing files, not a few sample frames, and ignores letter case on Windows and macOS. When a path has a version in both the folder and the filename, the filename's number is the one that moves.

Fixed

  • Auto-savePro overwrote the previous stereo still, because it checked for a file name stereo never writes. It now checks the left and right eye files, and no longer reports a false "auto-save failed".
  • Version Up on RenderPro now moves File Output nodes along as well, the same as the Version Up button, so an automatic version change no longer writes over the last take's passes.
  • Auto-savePro could overwrite the original still once 99 numbered copies existed. It now refuses and tells you.
  • ArchivePro could move an open .blend file, and archiving v1 could also sweep up v10 to v19.
  • Folder per VersionPro could reuse a folder that already held a take, and system files such as Thumbs.db could make it skip a version.
  • The version sync no longer renames the layers inside a multilayer EXR.
  • The Output panel no longer stutters on network drives, and no longer disappears when a path contains a null character.

1.0.2 2026-07-19

  • Check for Updates in Preferences.
  • Version Up could overwrite an existing take when the shot did not start at frame 1. Fixed.

1.0.1 2026-07-16

  • Relabelled the token buttons.

1.0.0 2026-07-15

  • First release. Free: token buttons with a live preview, date and version stamps, Version Up, folder helpers, copy path.
  • Pro: path presets with a global favorite, camera and pass folders, archive on Version Up, auto-saved F12 renders.
