07 / FAQ

Before you buy.

Does it change how Blender renders?+

No. It writes a normal output path with Blender's own tokens. Remove the add-on and the path still renders, so a render farm needs nothing installed.

Can it still overwrite a render?+

Version Up skips versions that already hold files, auto-save adds _1, _2 to a taken name, and the preview warns when Overwrite is off with files already there. Blender itself will still write wherever you point it by hand.

Does anything run on its own?+

Auto-save for stills is on by default in Pro. Version Up on Render and Archive on Version Up stay off until you turn them on in Preferences.

How do updates arrive?+

Connect Superhive as a remote repository in Blender once, and Blender finds and installs new versions for you.

Anything it leaves alone?+

Folder per Version leaves the emptied version folder in place. File Output nodes with no version in their path are not touched.
